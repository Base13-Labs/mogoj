# Context Index

Multi-keyword -> doc mapping. Multiple keywords point to same doc.
Look up any keyword, find all related conversations, decisions, and docs.

**How to use:** Search keyword -> get doc list -> read hot (direct) refs first -> follow warm (second-degree) refs if needed.

**Update rule:** Every `/mogoj-save` appends new keywords here. Never remove old entries — mark `[archived]` if obsolete.
