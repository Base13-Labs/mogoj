# Support

Mogoj is community-supported open-source software maintained by Base13 Labs on a best-effort basis. There is no guaranteed response time, service-level agreement, hosted service, or recovery service.

- Installation trouble: use the installation-help issue form and include `mogoj doctor --json` output after removing private paths.
- Confirmed bugs: use the bug report form with synthetic reproduction data.
- Product ideas: use the feature request form.
- Vulnerabilities: follow `SECURITY.md`; never report them publicly.

Before filing, search existing issues and test the newest beta. Never attach a real memory store, SQLite database, backup, credential, or confidential log.
