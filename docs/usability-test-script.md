# Beginner installation test

Give a participant unfamiliar with Python packaging only the primary install command. Ask them to narrate expectations and complete install → onboarding → save → rebuild → search → doctor → uninstall.

Record platform, completion, time to first save and recall, unfamiliar words, failed copied commands, doctor result, uninstall result, and whether memory survived. Do not collect their memory content or private paths. Success requires no profile edit or manual symlink. File sanitized findings as issues.
