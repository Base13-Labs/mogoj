# Security policy

## Supported versions

During beta, only the newest published beta receives security fixes. Base13 Labs maintains this project on a best-effort basis and cannot guarantee response or remediation times.

## Report privately

Do not open a public issue for a vulnerability or include real credentials or private memory in a reproduction. Use GitHub's [private vulnerability reporting form](https://github.com/Base13-Labs/mogoj/security/advisories/new). Include the affected version, impact, safe reproduction steps, and any proposed mitigation using synthetic data.

If the private form is unavailable, open a public issue that says only that you need a private security contact; do not disclose technical details until a maintainer establishes a private channel.

See [the security model](docs/security-model.md) for data boundaries, threat assumptions, and safe deployment guidance.
